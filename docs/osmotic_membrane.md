# Osmotic Membrane: Интеграция Оазисов в Legacy-мир

## Принцип полупроницаемой мембраны

Оазисы KORNET не являются изоляционистскими коммунами. Они действуют как **клетки с полупроницаемой мембраной** — обмениваются ресурсами с внешним миром, но сохраняют внутреннюю цитоплазму (кибернетическую логистику) непроницаемой для рыночной энтропии.

```
[ СТАРЫЙ РЫНОЧНЫЙ МИР ]                      [ ОАЗИС "KORNET" ]
(Фиат, инфляция, налоги)                     (Кибернетика, Джоули, РОЭ)
          │                                              │
          ▼                                              ▼
    ┌────────────────────────────────────────────────────────┐
    │     ОСМОТИЧЕСКИЙ ШЛЮЗ (Trade & Treasury Gateway)       │
    └───────────────────────────┬────────────────────────────┘
                                │
   Экспорт во внешний мир:      │  Внутренний контур:
   • Дешевая энергия            │  • Безналичное распределение
   • Роботизированная продукция │  • Полная автоматизация быта
   • Открытые патенты / Софт    │  • 100% покрытие базовых нужд
                                │
   Импорт сырья за фиат         │  Реинвестирование фиата в выкуп
   (на переходном этапе)        │  земли и масштабирование Оазисов
```

## Trade & Treasury Gateway

### Экспорт (Outbound)
1. **Энергия:** Оазисы с гелио/ветро/гео генераторами продают излишки энергии в внешнюю сеть по себестоимости (д+jоули + амортизация). Без маржи спекулянтов цена на 40-60% ниже рыночной.
2. **Роботизированная продукция:** 3D-печать, CNC, автоматические линии производят товары по чистой стоимости материалов. Никаких наценок за бренд, рекламу, дистрибьюторов.
3. **Открытые патенты / Софт:** Код и схемы Оазисов публикуются под GPLv3. Внешние компании могут использовать их, но любая модификация должна открываться.

### Импорт (Inbound)
1. **Сырье:** На переходном этапе Оазис еще не полностью автономен. Импортирует микрочипы, редкоземельные металлы, сложное оборудование за фиат.
2. **Экспертиза:** Приглашенные специалисты из внешнего мира получают фиатную компенсацию за консультации.

### Экономический демпинг
```
Себестоимость в Оазисе = Σ(Джоули_энергии + Амортизация_роботов + Стоимость_сырья)
Себестоимость на рынке  = Себестоимость_Оасиса + Налоги + Аренда + Зарплата_персоналу + Маржа_спекулянтов + Реклама

Результат: Товары Оазиса на 50-80% дешевле рыночных аналогов.
```

## Фазовый переход

1. **Этап 1 (0-10 000 участников):** Острова. Маленькие сообщества, работающие через приложение + локальный mesh.
2. **Этап 2 (10 000-100 000):** Оазисы. Первые физические пространства (арендованные земли, ко-work spaces) с полным циклом кибернетического управления.
3. **Этап 3 (100 000-1 000 000):** Кластеры. Оазисы объединяются в региональные сети. Внешние предприятия начинают интегрироваться в протокол, отдавая мощности в обмен на стабильную логистику и чистую энергию.
4. **Этап 4 (1 000 000+):** Активация ядра. Достаточная критическая масса для полной автономии от legacy-системы.

## Юридическая оболочка

- Оазисы регистрируются как **кооперативы** или **non-profit foundations**
- Trade & Treasury Gateway работает через **DAO-структуры** с multisig
- Экспорт энергии/продукции через **P2P-маркетплейсы** (Energy Web Chain, Power Ledger)
- Импорт сырья через обычные B2B-контракты на переходном этапе
